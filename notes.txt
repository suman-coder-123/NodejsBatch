built-in module :

1. FS module => file system module => this module allow node to intract with files and folder on our system 
create file => writeFileSync()
read file  => readFileSync()
update file  => appendFileSync()
delete file  => unlinkSync()
rename file  => renameSync()
folder create => mkdirSync()
delete folder => rmdirSync()
read the folders => readdirSync()
exists or not => existsSync()
